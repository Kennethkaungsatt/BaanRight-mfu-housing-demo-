BaanRight

Thai housing listings, translated into decisions — rent, deposit, phone, location and distance from MFU, in one click.

Team 16RideRight · Group 16 · demo 16 Nov

The problem

MFU students who don't read Thai can't read the rental market

  • Listings live in Thai Facebook groups: rent, deposit and phone number buried in free text.
  • Translating by hand costs minutes per post — the good rooms are taken first.
  • The details that decide a visit are the ones machine translation mangles: deposit months, soi names, distance to campus.

A typical post

ห้องให้เช่า ซอยแม่จันใต้ 3
ค่าเช่า 6000 บาท/เดือน
ประกัน 1 เดือน
ห่างจากมหาวิทยาลัย 10 นาที
สนใจโทร 081-234-5678

What a student needs

฿6,000 / month · 1 month deposit · 10 min from MFU · 081-234-5678

Who it's for

Three moments, one product

1 · Find

Paste a post → read rent, deposit, phone, soi and distance in English → call the landlord.

2 · Compare

Save listings → search and shortlist with ★ → export CSV and compare side by side.

3 · Reply

Tick the questions that matter → get a Thai message ready to paste into Messenger.

Same workflow in the Chrome extension (inside Facebook) and in the web prototype (any device).

Live demo

What we'll show in 4 minutes

  1. Load demo post → Translate. Price hero, details grid, distance row.
  2. Save the listing, reload the page — it's still there.
  3. Search + shortlist, then export the CSV.
  4. Ask the landlord: tick three questions → Thai message → copy.
  5. Extension in the wild: right-click a Thai Facebook post → Translate with BaanRight.

What's built

Features, both surfaces

Translate & extract

Chunked th→en translation plus price, deposit, phone, location and availability.

Distance to MFU

Stated minutes, map links, or the Fah Thai market landmark — never a blank cell.

Saved + shortlist

Searchable list, ★ filter, one-tap call, original post link, photo thumbnails.

Photos

Add, paste or drag photos into the tray; they save with the listing and download later.

Ask the landlord

Five common questions translated into Thai and copied in one tap.

Export & alerts

CSV export for comparing, area + budget alerts, light/dark theme, autosaved drafts.

Under the hood

One core, two surfaces, no backend

Extractors, translation client and storage shape are shared — the web prototype behaves exactly like the extension.

Quality

Tested where it matters

Automated

  • 11/11 unit tests pass — node --test tests/extractors.test
  • Deposit formats, Thai digits, floor-area vs. location, trailing phone numbers
  • Translation errors: quota text, HTTP 429, other statuses

Manual

  • Real Facebook posts in the extension
  • Responsive check at 360 / 768 / 1440 px
  • Dark-theme contrast on key text pairs
  • Full demo dry-run before class

Honest limits

What isn't there yet

  • Screenshot OCR — not implemented; the UI says so instead of failing silently.
  • Translation — free MyMemory tier with a fair-use quota; no offline mode.
  • Distance — the landlord's figure, a map link, or a landmark estimate, not a routed walk.
  • Storage — browser only, no account, no sync between devices.
